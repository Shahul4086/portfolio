Crop recommendation engine

SITUATION

Choosing the wrong crop for a plot's soil and climate costs a farmer an entire season. The decision is usually made from habit rather than from the soil's actual nutrient profile.

TASK

Build a recommendation module that turns measurable readings into a clear suggestion a non-technical user can act on.

ACTION

Cleaned and prepared the dataset with Pandas and NumPy, handling missing values and scaling the numeric features. Trained Random Forest, Decision Tree and K-Nearest Neighbors classifiers on nitrogen, phosphorus, potassium, temperature, humidity, pH and rainfall, then compared their accuracy to select the model to ship.

RESULT

A working prediction module that returns a crop recommendation from seven inputs, wired into the desktop application so it is usable without touching code.

Farm management desktop app

SITUATION

A prediction model is only useful if someone can actually run it, and farm records were being kept on paper with no history to analyse.

TASK

Deliver the model as a usable application with persistent storage for day-to-day farm records.

ACTION

Built a desktop interface in Tkinter and integrated it with MySQL. Designed tables and queries for farm activities, expenses and yields, and added modules for logging activity, tracking spend and reviewing yield over time.

RESULT

An end-to-end application: data in, model trained, predictions served through a UI, and every record stored and queryable afterwards.
